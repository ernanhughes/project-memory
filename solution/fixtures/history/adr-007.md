# ADR-007 — event-store target

date: 2024-07-11
status: accepted
deciders: m.okafor, j.lindqvist

Decision (evt-205): new event-store work should target PostgreSQL.

Context: the SQLite prototype (evt-201) suffered concurrent-write
contention under load (evt-202, evt-203). The PostgreSQL candidate held
flat throughput to 32 writers (evt-204).

Consequences: the event-store service migrates to PostgreSQL; new
services copy the PostgreSQL setup, not the SQLite prototype. This
decision supersedes evt-201.
